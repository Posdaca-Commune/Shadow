# Shadow 1.1.3

Shadow `1.1.3` hardens the Paradox launcher plugin (error handling, atomic
state writes, mod descriptor hardening) and adds early Linux support to path
discovery, file manager integration, and game launching.

## Highlights

- Linux support in the bundled launcher plugin: Steam library and Paradox user
  directory discovery (including Flatpak Steam), native Linux executable
  candidates, cross-platform file manager and URL opening, and a
  `steam://rungameid` launch fallback when no native executable is configured.
- A failed refresh no longer leaves the plugin stuck in the loading state with
  the launch button disabled; errors surface in the status bar instead.
- Generated `ugc_*.mod` descriptor file names sanitize `remote_file_id`, so
  third-party mod files cannot escape the mod directory via path traversal.
- `launcher-state.json` is written atomically, corrupt state files are backed
  up before being rebuilt, and settings/state I/O failures no longer crash the
  app.
- Paradox playset import surfaces database errors instead of reporting "no
  playsets found"; save discovery skips individual locked saves instead of
  failing the whole refresh.
- Packaging scripts (MSIX/macOS/Linux) fail fast on native command errors and
  use portable paths; the Linux tarball ships with executable bits, LF line
  endings, and extracts to the extraction root.
- New `Shadow.Tests` unit test suite; CI runs it on Windows, Linux, and macOS.
- Microsoft.Data.Sqlite upgraded from 11.0.0-preview.7 to the 10.0.11 stable
  release.

## Download

Use `Shadow-1.1.3.msix` on Windows 10/11 x64. Install with Windows App
Installer, then start Shadow from the Start menu. After install, the `shadow`
app execution alias is available in a terminal.

A portable Linux tarball (`Shadow-1.1.3-linux-x64.tar.gz`, built from CI) can be
extracted anywhere; run `./Shadow.sh` from the extraction directory.

## Notes

- The `steam://rungameid` fallback cannot forward launch arguments; configure
  the native executable in Game Settings to pass arguments such as `-debug`.
- See `CHANGELOG.md` for the full list of changes since `1.1.2`.
