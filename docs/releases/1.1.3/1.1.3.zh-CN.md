# Shadow 1.1.3

Shadow `1.1.3` 加固了 Paradox 启动器插件（错误处理、原子状态写入、Mod 描述符
防穿越），并为路径发现、文件管理器集成和游戏启动加入初步 Linux 支持。

## 重点

- 内置启动器插件的 Linux 支持：Steam 库与 Paradox 用户目录发现（含 Flatpak
  Steam）、Linux 原生可执行文件候选、跨平台的文件管理器与 URL 打开，以及未
  配置可执行文件时通过 `steam://rungameid` 启动的回退。
- 刷新失败不再使插件停留在加载状态、启动按钮永久禁用；错误会显示在状态栏。
- 生成 `ugc_*.mod` 描述符文件名时对 `remote_file_id` 做消毒，第三方 Mod 文件
  无法通过路径穿越逃出 mod 目录。
- `launcher-state.json` 改为原子写入，损坏文件先备份再重建；设置与状态文件
  的 IO 失败不再导致崩溃。
- Paradox 播放集导入会显示数据库错误，而不是误报"没有播放集"；存档发现会
  跳过单个被占用的存档，不再导致整次刷新失败。
- 打包脚本（MSIX/macOS/Linux）对原生命令失败立即报错并使用可移植路径；
  Linux tar 包携带可执行位、LF 行尾，解压即得根目录结构。
- 新增 `Shadow.Tests` 单元测试；CI 在 Windows、Linux、macOS 上运行测试。
- Microsoft.Data.Sqlite 从 11.0.0-preview.7 升级到 10.0.11 稳定版。

## 下载

Windows 10/11 x64 用户下载 `Shadow-1.1.3.msix`，用 Windows 应用安装程序安装后，
从开始菜单启动 Shadow。安装后可在终端使用 `shadow` 应用执行别名。

CI 构建的 Linux 便携包（`Shadow-1.1.3-linux-x64.tar.gz`）解压到任意目录后，
在解压目录运行 `./Shadow.sh` 即可。

## 说明

- `steam://rungameid` 回退无法转发启动参数；如需传递 `-debug` 等参数，请在
  游戏设置中配置原生可执行文件。
- 完整变更列表见 `CHANGELOG.md` 与 `docs/CHANGELOG.zh-CN.md`。
