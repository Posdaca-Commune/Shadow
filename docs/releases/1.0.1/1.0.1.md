# Shadow 1.0.1

Shadow `1.0.1` is a maintenance update to the stable plugin-based Paradox launch
pad shell. It improves first-run setup and playset drag interactions, and polishes
card layout across the launcher.

## Highlights

- Automatic discovery of installed Paradox game directories, with manual
  directory selection in game settings.
- New playsets start empty instead of copying the current playset's mods.
- Drag-reorder insert indicator is anchored below the preceding card, with
  symmetric flip thresholds in both drag directions.
- The "Add mod" dialog keeps card content in place when selecting.
- Refined card margins across launcher sections.

## Download

Use `Shadow-1.0.1.msix` on Windows 10/11 x64. Install with Windows App Installer,
then start Shadow from the Start menu. After install, the `shadow` app execution
alias is available in a terminal.

## Notes

- Back up Paradox game user directories before switching launchers for important playsets.
- See `CHANGELOG.md` for the full list of changes since `1.0.0`.
