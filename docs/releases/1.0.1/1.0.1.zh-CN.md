# Shadow 1.0.1

Shadow `1.0.1` 是插件化 Paradox 启动台壳层稳定版的维护性更新，改进首次
配置体验与播放集拖拽交互，并优化启动器各处的卡片布局。

## 重点

- 自动查找已安装的 Paradox 游戏目录，并可在游戏设置中手动选择。
- 「添加 Mod」对话框支持多选：单击选中、再次单击取消，可一次添加多个 Mod。
- 新建播放集改为创建空播放集，不再复制当前播放集的 Mod。
- 拖拽排序插入指示条统一锚定在上一张卡片下方，向上 / 向下翻转手感对称。
- 「添加 Mod」对话框选中卡片时内容不再位移。
- 调整启动器各分区的卡片边距。

## 下载

Windows 10/11 x64 用户下载 `Shadow-1.0.1.msix`，用 Windows 应用安装程序安装后，
从开始菜单启动 Shadow。安装后可在终端使用 `shadow` 应用执行别名。

## 说明

- 在把 Shadow 作为重要播放集主启动器前，请先备份游戏用户配置目录。
- 完整变更列表见 `CHANGELOG.md` 与 `docs/CHANGELOG.zh-CN.md`。
