# Shadow 1.0.0

Shadow `1.0.0` 是插件化 Paradox 启动台壳层的首个稳定版，包含桌面主程序、
插件抽象项目，以及内置的多游戏 Paradox 启动器插件。

## 重点

- 主页启动台：插件状态、快捷操作和配置引导。
- Avalonia/Fluent 桌面主程序，支持运行时加载插件。
- 多游戏 Paradox 启动器：播放集、Mod、DLC、游戏设置和启动。
- 命令行启动：`shadow PDXGameLauncher <game>`。
- 支持 Windows MSIX 打包分发。

## 下载

Windows 10/11 x64 用户下载 `Shadow-1.0.0.msix`，用 Windows 应用安装程序安装后，
从开始菜单启动 Shadow。安装后可在终端使用 `shadow` 应用执行别名。

## 说明

- 在把 Shadow 作为重要播放集主启动器前，请先备份游戏用户配置目录。
- 请在启动器插件中配置游戏可执行文件、用户目录和 Workshop 路径。
- 相对 `1.0.0-beta.1` 的完整变更见 `docs/CHANGELOG.zh-CN.md`。
