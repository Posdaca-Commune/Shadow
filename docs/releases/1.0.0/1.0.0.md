# Shadow 1.0.0

Shadow `1.0.0` is the first stable release of the plugin-based Paradox launch pad
shell. It includes the desktop host, the plugin abstraction project, and the
bundled multi-game Paradox Game Launcher plugin.

## Highlights

- Home launch pad with plugin status, quick actions, and setup guidance.
- Avalonia/Fluent desktop host with runtime plugin loading.
- Multi-game Paradox launcher for playsets, mods, DLC, game settings, and launch.
- Command-line launch through `shadow PDXGameLauncher <game>`.
- MSIX packaging for Windows distribution.

## Download

Use `Shadow-1.0.0.msix` on Windows 10/11 x64. Install with Windows App Installer,
then start Shadow from the Start menu. After install, the `shadow` app execution
alias is available in a terminal.

## Notes

- Back up Paradox game user directories before switching launchers for important playsets.
- Configure the game executable, user folder, and Workshop path in the launcher plugin.
- See `CHANGELOG.md` for the full list of changes since `1.0.0-beta.1`.
