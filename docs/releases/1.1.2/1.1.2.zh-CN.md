# Shadow 1.1.2

Shadow `1.1.2` 将 Mod 导入从仅支持 zip 压缩包改为文件夹导入，并将刷新和
存档发现移至后台线程，加载时显示遮罩。

## 重点

- Mod 导入改为选择文件夹而非压缩包。选择一个 Mod 文件夹后，Shadow 会将
  其内容复制到 Paradox `mod/` 目录，并自动生成对应的 `.mod` 索引描述符文件。
- 刷新和存档发现改为在后台线程执行，加载期间显示遮罩，避免界面卡顿。
- 移除了 `1.1.1` 中误引入的重复本地化键。
- 修复本地 Mod 的 `.mod` 文件名含大小写字母时（如 `ATA.mod`、`AED.mod`）
  无法在 HOI4 中加载的问题。启动器现在解析磁盘上的实际文件名，确保
  `dlc_load.json` 中的大小写与文件一致。

## 下载

Windows 10/11 x64 用户下载 `Shadow-1.1.2.msix`，用 Windows 应用安装程序安装后，
从开始菜单启动 Shadow。安装后可在终端使用 `shadow` 应用执行别名。

## 说明

- Mod 导入对话框现在打开的是文件夹选择器，而非文件选择器。
  请选择包含 `descriptor.mod` 的文件夹（或包含单个嵌套子文件夹的目录）。
- 完整变更列表见 `CHANGELOG.md` 与 `docs/CHANGELOG.zh-CN.md`。
