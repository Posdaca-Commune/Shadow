# Shadow 1.1.2

Shadow `1.1.2` replaces the zip-only mod import with folder-based import, and
moves refresh and save discovery off the UI thread with a loading overlay.

## Highlights

- Mod import now accepts a folder instead of a zip archive. Select a mod folder
  and Shadow copies it into the Paradox `mod/` directory, then auto-generates the
  corresponding `.mod` descriptor file.
- Refresh and save discovery now run on a background thread. A loading overlay
  keeps the interface responsive during heavy mod and DLC discovery.
- Removed duplicate localization keys that were accidentally introduced in
  `1.1.1`.
- Fixed local mods with mixed-case `.mod` file names (e.g. `ATA.mod`, `AED.mod`)
  not loading in HOI4. The launcher now resolves the actual on-disk file name so
  the casing in `dlc_load.json` matches the real file.

## Download

Use `Shadow-1.1.2.msix` on Windows 10/11 x64. Install with Windows App Installer,
then start Shadow from the Start menu. After install, the `shadow` app execution
alias is available in a terminal.

## Notes

- The mod import dialog now opens a folder picker instead of a file picker.
  Select the folder that contains the mod's `descriptor.mod` (or a single nested
  subfolder containing it).
- See `CHANGELOG.md` for the full list of changes since `1.1.1`.
