# Shadow 1.1.1

Shadow `1.1.1` 对 `1.1.0` 引入的存档管理分区进行了改进。存档现在会显示
游戏内日期和国家元数据，同时移除了备份 / 恢复功能，改为更简洁的浏览、
搜索和删除流程。

## 重点

- 存档元数据解析：每张存档卡片显示游戏内日期标签，以及（如可用）国家代码
  （HOI4）或帝国名称（群星）。
- 每张存档卡片新增「在文件夹中显示」按钮，可在资源管理器中定位存档文件
  （群星类文件夹型存档则定位到对应目录）。
- 群星文件夹型存档支持：每个存档目录（含多个带时间戳的 `.sav` 文件）显示为
  单个卡片并标注文件数。
- 移除存档分区的备份 / 恢复功能；工具栏改为单个「打开存档目录」按钮。
- 存档目录解析改为大小写不敏感，并统一处理下划线 / 空格变体。

## 下载

Windows 10/11 x64 用户下载 `Shadow-1.1.1.msix`，用 Windows 应用安装程序安装后，
从开始菜单启动 Shadow。安装后可在终端使用 `shadow` 应用执行别名。

## 说明

- 存档元数据从 ZIP 的 `meta` 条目解析（群星 / CK3 / EU4 / 维多利亚 3），
  或从二进制文件头与文件名解析（HOI4）。仅读取轻量字段，不解析完整游戏状态。
- 存档删除现已不可恢复。删除前请手动备份重要存档。
- 完整变更列表见 `CHANGELOG.md` 与 `docs/CHANGELOG.zh-CN.md`。
