# Shadow 1.1.1

Shadow `1.1.1` refines the save management section introduced in `1.1.0`.
Saves now show in-game date and country metadata, and the backup/restore feature
has been removed in favor of simpler browse, search, and delete workflows.

## Highlights

- Save metadata parsing: each save card shows an in-game date badge and, where
  available, a country tag (HOI4) or empire name (Stellaris).
- "Reveal in folder" button on each save card to locate the save file (or folder
  for Stellaris-style saves) in Windows Explorer.
- Folder-based save support for Stellaris: each save directory containing
  multiple timestamped `.sav` files is shown as a single card with a file-count
  badge.
- Removed the backup/restore feature from the save section; the toolbar now has a
  single "open save folder" button.
- Save directory resolution is now case-insensitive and normalises
  underscore/space variants.

## Download

Use `Shadow-1.1.1.msix` on Windows 10/11 x64. Install with Windows App Installer,
then start Shadow from the Start menu. After install, the `shadow` app execution
alias is available in a terminal.

## Notes

- Save metadata is parsed from the ZIP `meta` entry (Stellaris/CK3/EU4/Vic3) or
  from the binary file header and filename (HOI4). Only lightweight fields are
  read; the full gamestate is not parsed.
- Save deletion is now irreversible. Back up important saves manually before
  deleting.
- See `CHANGELOG.md` for the full list of changes since `1.1.0`.
