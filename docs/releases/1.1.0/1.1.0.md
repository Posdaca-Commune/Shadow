# Shadow 1.1.0

Shadow `1.1.0` adds save management to the plugin-based Paradox launch pad shell,
alongside the setup and drag-interaction improvements from `1.0.1`.

## Highlights

- New "Saves" section: browse saves for the selected game with timestamps,
  sizes, and backup counts.
- Back up a save to the Shadow workspace, restore from any backup, and delete
  saves while keeping their backups.
- Save search and total saves/backups counters; open the save folder directly.
- Per-game save support for HOI4, CK3, EU4, Stellaris, Victoria 3, and
  Imperator: Rome.
- From `1.0.1`: automatic game directory discovery with manual selection,
  multi-select mod adding, empty new playsets, and consistent drag-to-reorder.

## Download

Use `Shadow-1.1.0.msix` on Windows 10/11 x64. Install with Windows App Installer,
then start Shadow from the Start menu. After install, the `shadow` app execution
alias is available in a terminal.

## Notes

- Back up Paradox game user directories before switching launchers for important playsets.
- Save backups live under `%APPDATA%\Posdaca\<Game>\save-backups`; restoring a
  backup overwrites the current save file.
- See `CHANGELOG.md` for the full list of changes since `1.0.0`.
