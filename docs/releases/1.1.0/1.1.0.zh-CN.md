# Shadow 1.1.0

Shadow `1.1.0` 为插件化 Paradox 启动台壳层新增存档管理功能，并包含
`1.0.1` 的配置体验与拖拽交互改进。

## 重点

- 新增「存档」分区：浏览当前游戏的存档，显示保存时间、大小和备份数。
- 一键备份存档到 Shadow 工作区、从任意备份恢复，删除存档时保留备份。
- 存档搜索与存档 / 备份总数统计，可直接打开存档目录。
- 支持 HOI4、CK3、EU4、群星、维多利亚 3、Imperator: Rome 的存档识别。
- 来自 `1.0.1`：游戏目录自动查找与手动选择、多选添加 Mod、空播放集、
  一致的拖拽排序。

## 下载

Windows 10/11 x64 用户下载 `Shadow-1.1.0.msix`，用 Windows 应用安装程序安装后，
从开始菜单启动 Shadow。安装后可在终端使用 `shadow` 应用执行别名。

## 说明

- 在把 Shadow 作为重要播放集主启动器前，请先备份游戏用户配置目录。
- 存档备份保存在 `%APPDATA%\Posdaca\<游戏>\save-backups`；恢复备份会覆盖
  当前存档文件。
- 完整变更列表见 `CHANGELOG.md` 与 `docs/CHANGELOG.zh-CN.md`。
